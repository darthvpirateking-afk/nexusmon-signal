# NEXUSMON Agent Routing

Before meaningful build, repair, system-design, automation, agent, or model work, read:

- `NEXUSMON_AGENCY_AMPLIFICATION.md`

Operate by:

```text
DESCRIBE → MATERIALIZE → VERIFY → OBSERVE → REFINE → AUTOMATE → REUSE → COMPOUND → REPEAT
```

Every meaningful mission should leave behind the requested result and, where a real reusable pattern was learned, capability residue that makes future work easier.

Before finishing, answer:
- What assumptions were wrong?
- What broke first?
- What became painful?
- What should have been automated?
- What can be reused?
- What system would make the next project easier?

Preserve repository-specific authority and safety boundaries. Capability is not authority. Proof is not permission. Source proof is not runtime proof. Unknown is valid. Find and reuse existing owners before creating new frameworks.

Do not finish meaningful engineering work with only "Task Complete." Finish with RESULT, PROOF, TRUTH STATE, CAPABILITY RESIDUE, remaining UNKNOWN/BLOCKER, and the strongest compounding next move.
